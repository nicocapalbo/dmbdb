# Support

## Before asking for help

1. Check the [DUMB documentation](https://dumbarr.com/), especially the
   [frontend guides](https://dumbarr.com/frontend/).
2. Confirm whether the problem is in dmbdb, the DUMB backend, or an embedded
   upstream service.
3. Re-test on the latest applicable release or `dev` branch.
4. Collect the dmbdb and DUMB versions, browser information, reproduction
   steps, and sanitized logs or screenshots.

## Where to ask

- Use a
  [dmbdb help request](https://github.com/nicocapalbo/dmbdb/issues/new/choose)
  for frontend setup, behavior, or troubleshooting.
- Use the [DUMB Discord](https://discord.gg/8dqKUBtbp5) for community
  discussion and real-time troubleshooting.
- Use the [DUMB repository](https://github.com/I-am-PUID-0/DUMB) when the
  backend API, service setup, configuration, or lifecycle behavior is the
  source of the problem.
- Report issues in an embedded application to its upstream project when dmbdb
  only displays the upstream behavior.

For vulnerabilities, follow [SECURITY.md](SECURITY.md) and report privately.
Do not use public support channels.
